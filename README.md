# AI-jin

AI ผู้ช่วยส่วนตัวสำหรับการเรียน การทำงาน และการใช้ชีวิต

## เป้าหมาย

ช่วยให้ผู้ใช้
- เรียนรู้ได้ง่ายขึ้น
- ทำงานได้เร็วขึ้น
- จัดการชีวิตได้ดีขึ้น

## ฟีเจอร์หลัก

### Home
- แสดงงานวันนี้
- แสดงเป้าหมายวันนี้

### AI Chat
- คุยกับ AI
- ถามคำถาม
- สรุปข้อมูล

### Tasks
- เพิ่มงาน
- ลบงาน
- ติดตามงาน

### Daily Summary
- สรุปสิ่งที่ทำในแต่ละวัน
- แนะนำสิ่งที่ควรทำพรุ่งนี้

## การทำงานรายวัน

เช้า:
- AI วิเคราะห์แผนงาน

กลางวัน:
- AI ช่วยจัดการงานใหม่

เย็น:
- AI สรุปผลทั้งวัน
